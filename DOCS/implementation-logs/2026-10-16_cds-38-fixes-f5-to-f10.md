## Lessons Learned

- **Check the result before merging, and read the job, not the summary line.** #90's first `ui` run was red; the guard stopped the merge, and the log named the cause.
- **Fonts differ between machines.** The widened layout check passed on Windows and failed on Linux CI by 7 px (the header with doubled text). The check now names the elements that reach past the edge, and the header wraps. A check that depends on a machine's fonts must be run where CI runs it, or made robust to the difference.
- **A probe can pass for the wrong reason.** The first B-15 probe stayed green because the arranged closed card was in the persona with a stored balance of zero; the probe led to fixing the second persona's card.
- **`git checkout <file>` to undo a probe also undoes uncommitted work.** I lost an F5 edit that way and redid it; from then on the work was committed before probing.
- **A new hiding rule can widen a page.** `overflow: hidden` does not clip the cells of a table; hide a table with a wrapper.
- **The tooling quirks recur:** the shell strips backslashes, so scripts with regular expressions or newlines go through the Write tool; a `sed` that deletes a line containing a JSX attribute deletes the element.
